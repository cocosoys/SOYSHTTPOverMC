# 第7章 事件系统（使用与注册）

SOYSHTTPOverMC 通过 Bukkit 事件对外广播关键生命周期与网关事件。第三方插件直接 `registerEvents` 监听即可。

## 7.1 事件总表

| 事件 | 触发时机 | 线程 | 携带信息 |
| --- | --- | --- | --- |
| `SoysReadyEvent` | 主插件 `onEnable` 完成 | 同步（主线程） | 门面 API 实例 |
| `HttpConfigReloadEvent` | `/soyshttp reload` 完成后广播（等价 ReloadHttpConfigHandler） | 同步 | 无 |
| `GatewayRequestEvent` | 请求进入、策略判定前 | 异步（嗅探器线程池） | 方法/路径/IP/头 |
| `GatewayRequestServedEvent` | 请求处理完成 | 异步 | 状态码 + 耗时 |
| `GatewayAccessDeniedEvent` | 被策略链拒绝（401/403/426/429/500） | 异步 | 状态码 + 策略名 |
| `GatewayCredentialIssuedEvent` | `/soyshttp key` 或登录插件下发凭证后 | 同步 | 凭证对象 |
| `ApiRegisteredEvent` | API 端点注册完成 | 同步 | ApiInfo |
| `ApiUnregisteredEvent` | API 端点卸载完成 | 同步 | ApiInfo |
| `ApiAccessEvent` | 命中路由且通过权限判定后、处理器调用前 | worker → 切主线程发射 | 请求上下文 + 玩家名/玩家 |
| `ApiAccessDeniedEvent` | 权限不足（403） | 同步 | 玩家名/权限/路径 |

按请求类型细分的 API 访问事件（继承 `ApiAccessEvent`，与基类**共享同一 HandlerList**）：

- `ApiGetEvent` / `ApiPostEvent` / `ApiPutEvent` / `ApiDeleteEvent` / `ApiPatchEvent` / `ApiOtherEvent`

> 线程约束（1.12.2 强制）：**凭证下发 / API 注册 / 卸载类事件在同步主线程触发**——网关在 worker 线程直接触发异步事件会抛 `IllegalStateException`，故这些事件被设计为同步。

## 7.2 SoysReadyEvent（推荐首选）

解决第三方插件**早于 SOYS 加载**导致拿不到门面的问题：

```java
public class MyPlugin extends JavaPlugin implements Listener {

    @Override
    public void onEnable() {
        getServer().getPluginManager().registerEvents(this, this);
    }

    @EventHandler
    public void onSoysReady(SoysReadyEvent e) {
        SoysHttpOverMcApi api = e.getApi();
        api.getApiRegistration().registerController(new MyApi());
        api.getWebPage().registerPage(this, "/hello", bytes, "text/html");
    }
}
```

事件在 SOYS `onEnable` 完成后触发一次；若你的插件加载时 SOYS 已就绪（`HttpOverMcPlugin.getInstance() != null`），直接使用门面即可，无需依赖事件。

## 7.3 网关事件（异步）

```java
@EventHandler(ignoreCancelled = true)
public void onRequest(GatewayRequestEvent e) {
    if (e.getPath().startsWith("/api/console")) {
        // 记录敏感 API 访问日志
    }
}

@EventHandler
public void onServed(GatewayRequestServedEvent e) {
    if (e.getStatusCode() >= 500) {
        plugin.getLogger().warning("请求异常: " + e.getPath() + " -> " + e.getStatusCode());
    }
}

@EventHandler
public void onDenied(GatewayAccessDeniedEvent e) {
    plugin.getLogger().info("访问被拒绝: " + e.getIp() + " " + e.getPath()
            + " -> " + e.getStatusCode() + " (策略: " + e.getPolicyName() + ")");
}
```

`GatewayEvent` 是所有网关事件（请求/完成/拒绝/凭证/API 注册卸载）的抽象基类，可统一监听：

```java
@EventHandler
public void onGateway(GatewayEvent e) { /* 按 instanceof 分流 */ }
```

## 7.4 API 访问事件（同步）

```java
@EventHandler
public void onApiAccess(ApiAccessEvent e) {
    // e.getPlayerName() 玩家名（字符串，永不悬空）
    // e.getPlayer()    玩家实体（离线为 null）
    // e.getPath() / e.getMethod()
    long start = System.currentTimeMillis();
    // 注意：事件在处理器调用前触发；如需后置处理用 GatewayRequestServedEvent
}

@EventHandler
public void onGet(ApiGetEvent e) { /* 仅 GET */ }

@EventHandler
public void onApiDenied(ApiAccessDeniedEvent e) {
    plugin.getLogger().info("权限不足: " + e.getPlayerName() + " 访问 " + e.getPath());
}
```

`ApiAccessEvent` 与子类共享同一个 `HandlerList`：监听基类即收到所有类型；监听子类仅收到该类型（父监听不会阻止子类监听触发）。

## 7.5 注册 / 卸载事件（同步）

```java
@EventHandler
public void onApiRegistered(ApiRegisteredEvent e) {
    ApiInfo info = e.getApiInfo();
    // info: method / path / apiName / permission / ownerClass / ownerPlugin
    registerToMyDiscovery(info);
}

@EventHandler
public void onApiUnregistered(ApiUnregisteredEvent e) {
    removeFromMyDiscovery(e.getApiInfo());
}
```

## 7.6 事件与 reload

`/soyshttp reload` 完成后广播 `HttpConfigReloadEvent`（等价注册 `ReloadHttpConfigHandler` 钩子），第三方插件可在此重读自己的配置：

```java
@EventHandler
public void onReload(HttpConfigReloadEvent e) {
    myConfig.reload();
}
```

## 7.7 版本注意

- 所有事件在 1.12.2 与其余受支持版本上行为一致；1.6.4 / 1.7.10 的嗅探器线程池同样提供异步网关事件；
- 同步事件处理器内请勿做阻塞操作（会卡主线程 tick）。
