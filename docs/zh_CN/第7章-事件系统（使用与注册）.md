# 第7章 事件系统（使用与注册）

SOYSHTTPOverMC 通过 Bukkit 事件对外广播关键生命周期与网关事件。第三方插件直接 `registerEvents` 监听即可。

## 7.1 事件总表

事件按**抽象基类下的嵌套类**组织（包 `com.github.cocosoys.mc.soyshttpovermc.api.event`），按需 `import` 具体类即可：

| 事件（嵌套路径） | 触发时机 | 线程 | 携带信息 |
| --- | --- | --- | --- |
| `SoysReadyEvent`（顶层） | 主插件 `onEnable` 完成 | 同步（主线程） | 门面 API 实例 |
| `HttpConfigReloadEvent`（顶层） | `/soyshttp reload` 完成后广播 | 同步 | 无 |
| `GatewayEvent.GatewayRequestEvent` | 请求进入、策略判定前 | 异步（嗅探器线程池） | 方法/路径/IP/头 |
| `GatewayEvent.GatewayRequestServedEvent` | 请求处理完成 | 异步 | 状态码 + 耗时 |
| `GatewayEvent.GatewayAccessDeniedEvent` | 被策略链拒绝（401/403/426/429/500） | 异步 | 状态码 + 策略名 |
| `GatewayEvent.GatewayCredentialIssuedEvent` | `/soyshttp key` 或登录插件下发凭证后 | 同步 | 凭证对象 |
| `GatewayEvent.GatewayLoginResultEvent` | 玩家登录桥判定完成 | 同步 | 玩家/是否成功/原因/IP |
| `ApiEvent.ApiRegisteredEvent` | API 端点注册完成 | 同步 | `List<ApiInfo>` |
| `ApiEvent.ApiUnregisteredEvent` | API 端点卸载完成 | 同步 | `List<ApiInfo>` |
| `ApiEvent.ApiAccessEvent` | 命中路由且通过权限判定后、处理器调用前 | worker → 切主线程发射 | 请求上下文 + 玩家名/玩家 + 请求参数 + body |
| `ApiEvent.ApiAccessCompletedEvent` | API 请求处理完成（含被拒） | worker → 切主线程发射 | 上述 + 响应体/状态码/原因/响应头 |
| `WebResourcesEvent.WebResourcesAccessEvent` | 客户端请求 web 资源时 | 异步 | 路径/是否 html/js/结果（可跳转拦截） |
| `WebResourcesEvent.WebResourcesLoadedEvent` | 全部 web 资源加载完成后 | 异步 | `List<WebResourceAccess>` |

按请求类型细分的 API 访问事件（继承 `ApiEvent.ApiAccessEvent` / `ApiEvent.ApiAccessCompletedEvent`，与基类**共享同一 HandlerList**）：

- 访问前：`ApiGetEvent` / `ApiPostEvent` / `ApiPutEvent` / `ApiDeleteEvent` / `ApiPatchEvent` / `ApiOtherEvent`
- 访问完成：`ApiGetCompletedEvent` / `ApiPostCompletedEvent` / `ApiPutCompletedEvent` / `ApiDeleteCompletedEvent` / `ApiPatchCompletedEvent` / `ApiOtherCompletedEvent`

> 线程约束（1.12.2 强制）：**凭证下发 / API 注册 / 卸载类事件在同步主线程触发**——网关在 worker 线程直接触发异步事件会抛 `IllegalStateException`，故这些事件被设计为同步；访问/完成类事件经网关切回主线程发射。

## 7.2 SoysReadyEvent（推荐首选）

解决第三方插件**早于 SOYS 加载**导致拿不到门面的问题：

```java
public class MyPlugin extends JavaPlugin implements Listener {

    @Override
    public void onEnable() {
        getServer().getPluginManager().registerEvents(this, this);
    }

    @EventHandler
    public void onSoysReady(SoysReadyEvent e) {
        SoysHttpOverMcApi api = e.getApi();
        api.getApiRegistration().registerController(new MyApi());
        api.getWebPage().registerPage(this, "/hello", bytes, "text/html");
    }
}
```

事件在 SOYS `onEnable` 完成后触发一次；若你的插件加载时 SOYS 已就绪（`HttpOverMcPlugin.getInstance() != null`），直接使用门面即可，无需依赖事件。

## 7.3 网关事件（异步）

```java
@EventHandler(ignoreCancelled = true)
public void onRequest(GatewayRequestEvent e) {
    if (e.getPath().startsWith("/api/console")) {
        // 记录敏感 API 访问日志
    }
}

@EventHandler
public void onServed(GatewayRequestServedEvent e) {
    if (e.getStatusCode() >= 500) {
        plugin.getLogger().warning("请求异常: " + e.getPath() + " -> " + e.getStatusCode());
    }
}

@EventHandler
public void onDenied(GatewayAccessDeniedEvent e) {
    plugin.getLogger().info("访问被拒绝: " + e.getIp() + " " + e.getPath()
            + " -> " + e.getStatusCode() + " (策略: " + e.getPolicyName() + ")");
}
```

`GatewayEvent` 是所有网关事件（请求/完成/拒绝/凭证/登录结果）的抽象基类，可统一监听：

```java
@EventHandler
public void onGateway(GatewayEvent e) { /* 按 instanceof 分流 */ }
```

登录桥判定完成（含失败）可监听 `GatewayEvent.GatewayLoginResultEvent`：

```java
@EventHandler
public void onLoginResult(GatewayEvent.GatewayLoginResultEvent e) {
    if (!e.isSuccess()) {
        plugin.getLogger().info("登录失败: " + e.getPlayer() + " 原因: " + e.getReason());
    }
}
```

## 7.4 API 访问事件（同步）

```java
@EventHandler
public void onApiAccess(ApiEvent.ApiAccessEvent e) {
    // e.getPlayerName()  玩家名（字符串，永不悬空）
    // e.getPlayer()      玩家实体（离线为 null）
    // e.getPath() / e.getMethod()
    // e.getRequestParams()  请求参数（JSON / x-www-form-urlencoded 解析后的 map）
    // e.getBody()           原始请求体
    long start = System.currentTimeMillis();
    // 注意：事件在处理器调用前触发；如需后置处理用 ApiAccessCompletedEvent
}

@EventHandler
public void onGet(ApiEvent.ApiGetEvent e) { /* 仅 GET */ }

@EventHandler
public void onApiCompleted(ApiEvent.ApiAccessCompletedEvent e) {
    // 请求处理完成（含访问被拒）：e.getResponseBody() / e.getStatusCode() / e.getReason() / e.getHeaders()
    if (e.getStatusCode() >= 500) {
        plugin.getLogger().warning("API 异常: " + e.getPath() + " -> " + e.getStatusCode());
    }
}
```

`ApiEvent.ApiAccessEvent` 与子类共享同一个 `HandlerList`：监听基类即收到所有类型；监听子类仅收到该类型（父监听不会阻止子类监听触发）。完成类事件同理。

## 7.5 注册 / 卸载事件（同步）

```java
@EventHandler
public void onApiRegistered(ApiEvent.ApiRegisteredEvent e) {
    for (ApiInfo info : e.getApis()) {
        // info: method / path / apiName / permission / ownerClass / ownerPlugin
        registerToMyDiscovery(info);
    }
}

@EventHandler
public void onApiUnregistered(ApiEvent.ApiUnregisteredEvent e) {
    for (ApiInfo info : e.getApis()) {
        removeFromMyDiscovery(info);
    }
}
```

## 7.6 Web 资源事件（异步）

```java
@EventHandler
public void onWebAccess(WebResourcesEvent.WebResourcesAccessEvent e) {
    // e.getPath()   被请求资源路径（已含前缀）
    // e.isHtml() / e.isJs()   是否为 .html / .js 资源
    // e.getResult() 可跳转拦截 / 替换响应（redirect(...) / replace(...)）
    if (e.getPath().startsWith("/web/plugins/MCER") && !e.getResult().isHandled()) {
        e.getResult().redirect("/web/plugins/MCER/index");
    }
}

@EventHandler
public void onWebLoaded(WebResourcesEvent.WebResourcesLoadedEvent e) {
    for (WebResourceAccess r : e.getResources()) {
        // 全部资源加载完成（含 pages.yml / language.yml 注册项），可用于统计或二次登记
    }
}
```

## 7.7 事件与 reload

`/soyshttp reload` 完成后广播 `HttpConfigReloadEvent`（等价注册 `ReloadHttpConfigHandler` 钩子），第三方插件可在此重读自己的配置：

```java
@EventHandler
public void onReload(HttpConfigReloadEvent e) {
    myConfig.reload();
}
```

## 7.8 版本注意

- 所有事件在 1.12.2 与其余受支持版本上行为一致；1.6.4 / 1.7.10 的嗅探器线程池同样提供异步网关事件；
- 同步事件处理器内请勿做阻塞操作（会卡主线程 tick）。
