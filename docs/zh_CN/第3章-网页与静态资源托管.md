# 第三章 网页与静态资源托管

除了暴露接口，你往往还想给服务器做一个官网首页或管理后台网页。本插件提供了一套网页登记机制，让你用几行代码就能把网页挂到服务器网址下，并出现在门户首页导航中。

所有网页能力通过能力组 2（`WebPageApi`）提供。

## 3.1 网页登记模型

最直接的方式：把网页内容以字节数组登记到某个路径。

```java
api.getWebPage().registerPage(owner, "/hello", bytes);
api.getWebPage().registerPage(owner, "/hello", bytes, "text/html; charset=utf-8");
```

- `owner`：你的插件实例（`this`），用于归属标记与禁用时自动卸载；
- `path`：路由路径（非主插件会自动加 `/plugins/<插件名>` 前缀，同 API 规则）；
- `content`：网页字节；
- `contentType`：可选，指定 Content-Type；不指定时按扩展名推断。

> 磁盘热替换：运行时解压目录中的网页文件若已存在则不覆盖，支持在磁盘上直接修改后生效，无需重新打包插件。

## 3.2 批量目录托管

### 3.2.1 磁盘目录（惰性读 + 热替换）

把某个磁盘目录下的文件递归挂到某个 URL 前缀，请求时才读取文件，因此**支持磁盘热替换**：

```java
api.getWebPage().registerDirectory(owner, "/site", new File(getDataFolder(), "web"));
api.getWebPage().registerDirectory(owner, "/site", new File(getDataFolder(), "web"), false);
```

- `basePath`：URL 前缀；
- `dir`：磁盘目录；
- `proxy`（可选）：是否强制以主插件代理（无 `/plugins/<名>` 前缀）。

内部用 `Entry` 存储 `File` 并**惰性读取**，修改磁盘文件后刷新即生效。

### 3.2.2 插件 jar 内资源目录

把插件 jar 包内某资源前缀下的全部条目挂到 URL 前缀（适合把前端打包进 jar）：

```java
api.getWebPage().registerResourceDirectory(owner, "/assets", getClassLoader(), "web/assets");
api.getWebPage().registerResourceDirectory(owner, "/assets", getClassLoader(), "web/assets", false);
```

内部用 `JarFile` 扫描条目；读取时走 `ClassLoader`，注意 `Entry.resolveBytes()` 必须剥去前导 `/`（否则 body 恒空）。

## 3.3 门户导航项

让玩家在服务器门户首页（`/`）直接看到你的页面入口：

```java
api.getWebPage().registerNavItem(owner, "我的官网", "/site/home");   // 默认 order=100
api.getWebPage().registerNavItem(owner, "管理后台", "/admin", "⚙", "admin:access", 10);
```

属性：

| 参数 | 说明 |
| --- | --- |
| `label` | 导航显示名 |
| `path` | 点击跳转路径 |
| `icon` | 图标（可选） |
| `permission` | 所需权限（可选，无则所有人可见） |
| `order` | 排序（数字越小越靠前，默认 100） |

导航项最终注入门户首页的 `#soys-plugin-nav` 容器；插件禁用时**自动清理**，不会残留。

## 3.4 自定义 MIME 类型

扩展名到 Content-Type 的推断由 `MimeTypes` 负责。若你的静态资源用了非常规扩展名（如 `vue`、`ts`、`json5`），需先注册，浏览器才会按正确类型渲染：

```java
api.getToolkit().registerMimeType("vue", "text/html; charset=utf-8");
api.getToolkit().registerMimeType("ts",  "application/javascript; charset=utf-8");
```

> 重要：`Entry` 推断 Content-Type 时存的是 `null`，**请求时才实时计算**。因此若你“先 `registerDirectory` 后 `registerMimeType`”，新注册的 MIME 也会对之前登记的目录生效——无需重新登记。

也可通过 `api.getToolkit().guessContentType(path)` 查询某路径会被推断成什么类型。

## 3.5 错误页与 CORS

### 3.5.1 自定义错误页

替换通用 404 / 500 等错误响应：

```java
api.getWebPage().registerErrorPage(owner, 404, "<h1>页面走丢了</h1>".getBytes(StandardCharsets.UTF_8));
api.getWebPage().registerErrorPage(owner, 404, "<h1>页面走丢了</h1>");   // 便捷：HTML 字符串
```

插件禁用时自动卸载。

### 3.5.2 CORS 声明

为某路径前缀声明跨域头，便于前端独立部署时调用你的接口：

```java
api.getWebPage().registerCors(owner, "/api", "*",
    "GET,POST,PUT,DELETE,OPTIONS", "Content-Type,Authorization", true);
```

参数含义：

| 参数 | 说明 |
| --- | --- |
| `pathPrefix` | 路径前缀（`""` 或 `/` 表示全局） |
| `origin` | 允许来源，如 `*` 或 `https://a.com,https://b.com` |
| `methods` | 允许方法（可空=默认） |
| `headers` | 允许请求头（可空=`*`） |
| `credentials` | 是否允许携带凭证（Access-Control-Allow-Credentials: true） |

命中且为 `OPTIONS` 预检时，网关自动返回 `204 + CORS 头`（短路）；普通请求则附加 CORS 头。

## 3.6 代理前缀与跨服

### 3.6.1 强制代理无前缀

`registerProxyPage` / `registerProxyResource` 把网页以主插件身份登记（不带 `/plugins/<名>` 前缀）：

```java
api.getWebPage().registerProxyPage(owner, "/home", bytes);
api.getWebPage().registerProxyResource(owner, "/logo.png", getClassLoader(), "web/logo.png");
```

### 3.6.2 群组服下的 /server/<name>/ 前缀

在群组服（BungeeCord/Velocity）架构中，代理模块会把 `/server/<name>/` 前缀的请求剥除后，经 Phase1 `Forward` 跨服转发到对应子服的既有 Web 栈处理。你的网页按普通路径登记即可，跨服路由由代理侧完成。

## 3.7 大文件加载器（LargeFileLoader）

默认所有超过 `web.large-file-threshold` 的大文件由内置流式加载器处理。你也可以注册自定义加载器（例如对象存储），按路径前缀强行指定：

```java
api.getWebPage().registerLargeFileLoader(myLoader);              // 注册（同名覆盖）
api.getWebPage().setDefaultLargeFileLoader("object-storage");  // 全局切换默认加载器
api.getWebPage().setLargeFileLoader("/assets/map", "object-storage"); // 某前缀强制指定（最长前缀优先）
```

`LargeFileLoader` 是实现自定义大文件流式读取的 SPI 接口。

## 3.8 路由解析顺序与防护

`WebRegistry` 的解析顺序为：

1. 登录相关路径（`/auth/*`）；
2. 注解式 API（`getApiPrefix()` 下）；
3. `/favicon.ico`；
4. `WebRegistry` 登记的页面 / 资源；
5. 静态资源（磁盘 → jar → 404）。

并具备以下规则：

- **`..` 路径穿越防护**：拦截 `../` 类请求，防止越权读取服务器文件；
- **`.html` 智能匹配**：访问无扩展名路径时，先尝试 `path.html`，再尝试 `path/index.html`；
- **favicon**：磁盘优先 → jar → 204（空响应）。

你可以用 `soyshttp pages`（或 `shttp pages`，加 `all` 显示纯资源）查看当前已登记的页面与资源清单。
