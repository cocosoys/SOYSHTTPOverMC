# 第3章 网页与静态资源托管

SOYSHTTPOverMC 提供两套网页登记通道：**程序化登记**（`WebPageApi` → `WebRegistry`，供第三方插件）与**配置文件登记**（`pages.yml`，供管理员）。两者最终进入同一个路由表，由 `WebFrontendHandler` 统一伺服。

## 3.1 命名空间与路由约定

- **默认前缀**：第三方插件登记时自动补 `/web/plugins/<插件名>`，如插件 Foo 登记 `/dashboard` → 实际访问 `/web/plugins/Foo/dashboard`；
- **强制代理（无前缀）**：`registerProxyPage` / `registerProxyResource` 以主插件名义登记，不加前缀（如 `/dashboard`），owner 仍标记真实插件，卸载时一并清理；
- **昵称路由**：登记时可带 `nicknames` 列表，访问昵称路径同样命中本页面（如 `/主页`）；
- **.html 后缀智能匹配**：注册 `/login` 后，`/login` 与 `/login.html` 均可访问；
- **参数化路由**：路径含 `{name}` 占位符段（如 `/users/{id}`）自动登记到参数化路由表，匹配时提取 path variables（`resolveFull` 返回）；
- **目录索引兜底（index）**：访问 `/web/plugins/<插件名>`（或带尾斜杠）且常规解析未命中时，302 自动导航到 `…/index`（默认；经 .html 智能匹配命中 `index.html`）。`WebPageApi.setIndexRule(ownerName, enabled, indexFile)` 可按插件开关 / 改目标，默认全局启用；
- **SPA 回退声明**：`setSpaFallback(ownerName, enabled)` 声明后，该插件命名空间下**无扩展名**路径未命中时回退根 `index.html`（200，交前端 vue-router 判定）；**带扩展名**路径（.js/.css 等疑似静态资源）未命中仍返回 HTTP 404、绝不回退（避免旧 chunk 被 HTML 吞掉）。未声明插件保持原 404 语义；
- **跳转登记**：`registerRedirect` / `registerProxyRedirect`（WebRegistry）登记内部 302 跳转；`pages.yml` 中反引号包裹的值亦登记 302 跳转；
- **重复路径默认阻止**，`force=true` 强制覆盖并打印"强制登记的插件"。

## 3.2 门面能力组 2：WebPageApi

`api.getWebPage()` 提供（全部委托 `WebRegistry`）。**所有登记方法均返回登记成功的 `WebRegistry.Entry`**（含实际 path / owner 等；失败返回 `null`），批量登记返回 `Set<Entry>`；不再以 void 静默失败，方便开发者核对结果。

### 3.2.1 极简便捷登记（单/双参数，owner 沿调用栈自动识别）

接口最上方一组方法专为"极简登记"设计——只传内容即可，其余信息自动补充：

| 方法 | 自动补充内容 |
| --- | --- |
| `registerPage(byte[] content)` | path 自动 = `web/plugins/<插件>/page/page-<序号>`（每插件独立自增序号）；Content-Type 默认 `text/html; charset=utf-8` |
| `registerPage(String resourcePath)` | 登记 jar 内资源，path 自动 = `web/plugins/<插件>/page/<资源文件名不含后缀>`（如 `registerPage("web/index.html")` → `.../page/index`）；Content-Type 按扩展名推断 |
| `registerPage(String path, byte[] content)` | 显式路径 + 内容（自动补 `/web/plugins/<插件名>` 前缀） |
| `registerResource(String resourcePath)` / `registerResource(String path, String resourcePath)` | jar 内资源（惰性读取）；同上命名规则 |
| `registerProxyPage(String path, byte[] content)` / `registerProxyResource(String path, String resourcePath)` | 无 `/web/plugins/<插件名>` 前缀 |
| `registerErrorPage(byte[] content)` / `registerErrorPage(String html)` | 默认 404 状态码错误页 |
| `registerDirectory(File dir)` | basePath 自动 = `web/plugins/<插件>/<目录名>`，批量登记磁盘目录 |

owner 自动识别：沿调用栈 `JavaPlugin.getProvidingPlugin` 定位调用插件；识别失败回退主插件。

### 3.2.2 完整版登记（显式 owner / 全部参数）

| 方法 | 说明 |
| --- | --- |
| `registerPage(owner, path, byte[] content [, contentType] [, force])` | 登记网页（直接字节；Content-Type 按扩展名推断或显式指定） |
| `registerPage(owner, path, httpMethod, content, contentType, force, desc, nicknames)` | 非 GET 静态响应（POST/PUT/DELETE/PATCH） |
| `registerResource(owner, path, classLoader, resourcePath [, contentType] [, force])` | 登记插件 jar 内资源（按需读取，省内存） |
| `registerProxyPage(...)` / `registerProxyResource(...)` | 同上但无 `/web/plugins/<插件名>` 前缀 |
| `registerDirectory(owner, basePath, File dir [, proxy])` | 批量登记磁盘目录（递归，惰性读盘，支持热替换），返回 `Set<Entry>` |
| `registerResourceDirectory(owner, basePath, classLoader, resourceRoot [, proxy])` | 批量登记 jar 内资源目录，返回 `Set<Entry>` |
| `registerNetworkPage(owner, NetworkPage page)` | 登记网络页（访问时调 `page.load()` 取内容，可自定义加密传输） |
| `registerNetworkTransport(NetworkTransport)` | **预留**：登记网络传输提供者（当前仅占位存储 + 告警，未接入加载链路） |
| `registerLargeFileLoader(LargeFileLoader)` | 注册自定义大文件加载器（返回已注册实例） |
| `setDefaultLargeFileLoader(name)` / `setLargeFileLoader(pathPrefix, name)` | 切换默认 / 按路径前缀指定大文件加载方式 |
| `registerErrorPage(owner, status, byte[] content)` / `registerErrorPage(owner, status, String html)` | 注册自定义错误页（替换 404/500 等） |
| `unregisterPluginPages(pluginName)` | 卸载某插件名下全部网页 |
| `unregisterByTag(tag)` | 按来源 tag 卸载（pages.yml 重载用），返回卸载数量 |
| `unregisterCors(pluginName)` | 卸载某插件全部 CORS 声明 |
| `setIndexRule(ownerName, enabled, indexFile)` / `removeIndexRule(ownerName)` | 目录索引兜底规则（见 3.1） |
| `setSpaFallback(ownerName, enabled)` / `removeSpaFallback(ownerName)` | SPA 回退声明（见 3.1） |

示例：

```java
// 极简登记（仅内容，自动补路径与类型）
api.getWebPage().registerPage("<h1>Hello</h1>".getBytes(StandardCharsets.UTF_8));

// 直接内容
api.getWebPage().registerPage(this, "/hello",
        "<h1>Hello</h1>".getBytes(StandardCharsets.UTF_8), "text/html");

// jar 资源（resources/dist/notice.html）
api.getWebPage().registerResource(this, "/notice",
        getClass().getClassLoader(), "dist/notice.html");

// 磁盘目录批量（返回 Set<Entry>）
api.getWebPage().registerDirectory(this, "/app", new File(getDataFolder(), "webapp"));

// 带昵称 + 描述 + 权限的代理页（无前缀；权限参数见 WebRegistry 全参重载）
api.getWebPage().registerProxyPage(this, "/admin", null, bytes, "text/html", true,
        "管理后台", List.of("后台"));
// 带 AND 权限的登记（WebRegistry 全参重载，WebPageApi 门面未暴露权限位）：
webRegistry.registerProxyPage(this, "/admin", bytes, "text/html", true,
        "管理后台", List.of("后台"), List.of("soyshttp.page.admin"));
```

## 3.3 pages.yml（管理员配置）

`pages.yml` 由 `PagesConfig` 装配，分为三块：

### 3.3.1 web.* —— 前端根配置

```yaml
web:
  root: "/dist"            # 前端根：jar 内置 /dist/* 解压到 plugins/SOYSHTTPOverMC/web/ 并以磁盘目录为根
  home: "/index.html"      # 首页（访问 / 时伺服的内容）
  cache:
    max-bytes: 16777216    # LRU 缓存字节上限（默认 16MB）
    max-entries: 1024      # 缓存条目数上限
    ttl-seconds: 60        # 条目存活时间（秒）
    pinned: ["/", "/assets/"]   # 常驻内存清单（路径精确或目录前缀，不参与淘汰、不占 max-bytes）
  large-file-threshold: 16777216   # 超过视为大文件（不写缓存，走流式加载器）
  large-file-max-bytes: 134217728  # 大文件安全上限（超过拒绝加载，默认 128MB）
```

`web.home` 支持三种来源：相对/逻辑路径（如 `dist/index.html`）、绝对磁盘路径（`C:/sites/home.html`）、网络 URL（按需拉取并缓存约 5 分钟，失败回退默认首页）。

> 首次运行会把 jar 内置 `/dist/*` 解压到 `web/`；已存在的文件不会被覆盖（保留修改），磁盘缺失的文件回退 jar 内置。

### 3.3.2 pages.page / pages.auto —— 手动登记

```yaml
pages:
  page:
    "/":
      nicknames: ["主页"]
      description: "首页，可通过 '/主页' 昵称访问"
      resource: "dist/index.html"
      permissions: ["soyshttp.page.admin"]   # 可选：单页内联权限（见 3.5）
  auto:
    "/": "dist/"                            # 目录：递归注册文件夹下所有 .html
    "/link/mcmod": "`https://www.mcmod.cn/`"  # 反引号包裹 → 302 网络跳转
```

- `pages.page.<路径>.resource`：单个文件/资源来源，按扩展名推断 Content-Type（相对数据目录 / 绝对磁盘路径 / jar 内置 `/dist/...`）；
- `pages.auto`：键 = URL 路径，值 = 来源；单文件 / 目录（递归 .html）/ 反引号网络跳转；
- 全部使用**强制登记**（force），可覆盖核心或其它插件已注册的同路径页面；
- 每次服务器启动与 `/soyshttp reload` 重新装配。

### 3.3.3 卸载机制（tag）

pages.yml 注册的页面带 `tag = "pages.yml"`；reload 时先 `webRegistry.unregisterByTag("pages.yml")` 卸载旧登记，再重新注册——**已删除的路径/昵称不会残留内存**（`WebRegistry.unregisterByTag`）。

### 3.3.4 别名路由（pages.alias）

给任意已存在链接（含第三方插件页面 / API）新增"内部映射"别名，供服主 / 运维人员自行配置：

```yaml
pages:
  alias:
    "/网址/插件/ERP": "/web/plugins/MCERP"   # 键=别名、值=真实路径（一张平铺表）
    "/erp-admin":     "/web/plugins/MCERP"   # 支持多别名指向同一真实链接
```

语义：

- 别名命中后浏览器地址栏不变，按真实路径走完整解析（精确 / .html 智能 / 参数化 / 昵称 / index 兜底均生效）；
- **精确单路径、不做前缀映射**：子资源（如 `/web/plugins/MCERP/static/**`）仍走原路径，别名只做入口；
- 继承请求的 HTTP method（给 `/api/foo` 配别名后 GET/POST 都映射到同 method 的真实路径）；
- 仅跳转一层（真实路径不再查别名，防成环）；
- `/soyshttp pages` 列表末尾固定展示别名分区：`[✓]` = 目标可解析、`[⚠ 目标未登记]` = 未登记（访问将 404）。

## 3.4 内容缓存与性能

`WebContentCache`（`core/.../web/WebContentCache`）：

- **pinned 常驻**：命中项直接进常驻内存，不参与淘汰、不占用 `max-bytes`（用于门户首页等必须高频响应的资源）；
- **LRU + TTL**：仅对"惰性来源"生效（磁盘文件 / jar 资源，请求时读取）；`registerPage` 直接给定的字节不受控；
- **大文件**：超过 `large-file-threshold` 的磁盘文件不写缓存，交由 `LargeFileLoaderRegistry`（默认内置流式分块加载器）；超过 `large-file-max-bytes` 直接拒绝（防单文件打爆内存）。

## 3.5 网页访问权限

两级配置，权限节点为**字符串数组，AND 语义**（数组内全部通过才放行，任一缺失 → 302）：

1. `pages.page.<路径>.permissions` —— 单页内联（最高优先；与全局同路径时**完全替换、不合并**）；
2. `pages.permissions` —— 全局路径规则：

```yaml
permissions:
  "/admin":     ["soyshttp.page.admin"]      # 精确（含 /admin/... 子路径）
  "/console/*": ["soyshttp.page.console"]    # 目录通配
  "*":          ["soyshttp.page.guest"]      # 全量
```

路径匹配复用 `AuthUtils.matchesPath` 语义（`/admin` 精确、`/console/*` 目录通配、`*` 全量）。行为：

- **未登录** → 302 登录页 `login.html`；
- **已登录缺权限** → 302 权限不足提示页 `/perm-denied.html`（右上角 `i` 图标查看缺少的权限，含返回按钮回到被阻挡前的页面）；
- 权限节点复用组合权限服务（含本地权限表 `local`），可用 `/soyshttp perm` 授予 `soyshttp.page.xxx`；
- 仅对 HTML 页/跳转生效（css/js/图片等资源不拦）；登录页与提示页自身永不拦截。

程序化登记同样支持权限：`WebPageApi` 门面未暴露权限位，需经 **WebRegistry 全参重载**
（`registerPage(owner, path, content, contentType, force, desc, nicknames, permissions)` /
`registerProxyPage(...)` / `registerResource(...)` 同）——AND 语义，优先级低于 pages.yml 单页内联、高于全局。

## 3.6 错误页与 CORS

```java
// 自定义 404
api.getWebPage().registerErrorPage(this, 404, "<html>...</html>");

// CORS 声明（pathPrefix 为空或 "/" 表示全局；在 WebRegistry 层，门面无此方法）
webRegistry.registerCors(this, "/api", "*", "GET,POST", "Content-Type,Authorization", true);
```

命中 CORS 声明的 OPTIONS 预检请求 → 自动 204 + CORS 头（短路）；普通请求附加 CORS 头。

## 3.7 网络页（NetworkPage）

实现 `NetworkPage` 接口（`path()` / `name()` / `contentType()` / `cacheTtlSeconds()` / `load()`），在 `load()` 内实现拉取 + 解密 + 验签等自定义传输：

```java
api.getWebPage().registerNetworkPage(this, new NetworkPage() {
    public String path() { return "/secure"; }
    public byte[] load() throws Exception { return fetchAndDecrypt(); }
    public long cacheTtlSeconds() { return 60; }
});
```

## 3.8 版本注意

- 各版本 `MimeTypes` / 缓存 / 权限语义一致；1.6.4 / 1.7.10 的静态文件读取经 adapter 的 `YamlIo` 走显式 UTF-8。
